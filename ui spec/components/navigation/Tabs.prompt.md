Switches between peer views of the same data.

```jsx
<Tabs value={tab} onChange={setTab} items={[
  { id: "roles", label: "Open roles", count: 6 },
  { id: "sectors", label: "Growth sectors" },
]} />
```

The active underline tab is marked in rose — the only place rose appears in navigation. Use `variant="pill"` inside cards and panels.
