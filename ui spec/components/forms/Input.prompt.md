Single-line text field, label above in uppercase micro-type.

```jsx
<Input label="City" iconStart="map-pin" defaultValue="Portland, OR" hint="Metro area only" />
<Input label="Email" error="We could not read that address" />
```

Sizes `sm | md | lg`. Errors replace the hint. Inputs carry a faint inset well shadow — that is what separates them from buttons.
